# v0.1.0: local dashboard development preview

Release type: pre-release for local evaluation with disposable demo data. This is not a stable or production-ready release.

## Release notes

First development preview of Multi-Agents Dashboard: a React/Express/SQLite application for local OpenClaw-style workspaces.

- Task Manager, Org Chart, Standup, Workspace, and Docs views.
- Filesystem adapter with fixture fallback and SQLite persistence.
- Workspace file editing and markdown indexing.
- Template-based standup and job runners, meeting archives, and optional speech output.
- MIT license, installation documentation, existing interface screenshots, and contributor guidance.
- Correct compiled-server entry point for `npm run start`.

This preview includes synthetic usage data and simulated execution. It is not a production agent orchestrator. Authentication, restrictive network defaults, clear per-source provenance, dependency remediation, and automated runtime tests remain roadmap work.

## Validation and outstanding work

Validated on Windows with Node.js 22.22.0 and npm 10.9.4: locked dependency installation with scripts disabled followed by native addon/esbuild rebuild, TypeScript checks, production compilation, and the actual `npm run start` command. The built frontend and seven mission GET endpoints returned HTTP 200. A voice-disabled fixture standup completed with one turn and two persisted artifacts.

The following checks remain outstanding and are explicitly deferred beyond this development preview:

- Dependency remediation: the 2026-09-17 audit reported 12 vulnerable packages (6 high, 3 moderate, 3 low), including direct dependency Vite and transitive packages. Exposure has not been fully assessed. See [issue #5](https://github.com/MasterSaiyan04/Multi-Agents-Dashboard/issues/5).
- Network hardening: the server is unauthenticated, permits all CORS origins, and can listen beyond loopback. Keep it in an isolated environment, without sensitive files or public port exposure. See [issue #2](https://github.com/MasterSaiyan04/Multi-Agents-Dashboard/issues/2).
- Browser checks across all five views, disposable workspace save/reload, and optional speech were not validated. Automated runtime coverage is tracked in [issue #4](https://github.com/MasterSaiyan04/Multi-Agents-Dashboard/issues/4).
- A real workspace was not validated; demo success is not proof of live integration. See [issue #6](https://github.com/MasterSaiyan04/Multi-Agents-Dashboard/issues/6).
- Existing screenshots were preserved, not recaptured; they may reflect an earlier UI state.
- Fixture/imported/simulated provenance needs clearer UI treatment. See [issue #3](https://github.com/MasterSaiyan04/Multi-Agents-Dashboard/issues/3).

These limitations must be addressed or reassessed before a stable release. Publishing this preview does not establish eligibility or acceptance into any external program.

No adoption, download, user, or performance claims are part of these notes.
