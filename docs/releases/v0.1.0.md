# Proposed v0.1.0: local dashboard preview

Status: release proposal, not a tag or published release. The package remains at `0.0.0` until the release is approved and its checks are complete.

## Proposed release notes

First development preview of Multi-Agents Dashboard: a React/Express/SQLite application for local OpenClaw-style workspaces.

- Task Manager, Org Chart, Standup, Workspace, and Docs views.
- Filesystem adapter with fixture fallback and SQLite persistence.
- Workspace file editing and markdown indexing.
- Template-based standup and job runners, meeting archives, and optional speech output.
- MIT license, installation documentation, existing interface screenshots, and contributor guidance.
- Correct compiled-server entry point for `npm run start`.

This preview includes synthetic usage data and simulated execution. It is not a production agent orchestrator. Authentication, restrictive network defaults, clear per-source provenance, dependency remediation, and automated runtime tests remain roadmap work.
